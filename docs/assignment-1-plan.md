## Repository settings to configure

The repository owner should configure these GitHub settings and record completion in this document:

- Give all three team members the access needed for their responsibilities.
- Protect `main`.
- Require a pull request before merging.
- Require at least one approval.
- Dismiss stale approvals when substantive changes are pushed, if available.
- Require conversation resolution before merging.
- Prevent force pushes and deletion of `main`.
- Enable automatic deletion of merged branches.
- Add required status checks after the project has real automated checks.

These settings live on GitHub and cannot be proven by repository files alone. Capture a screenshot or brief configuration record for the assignment if the instructor expects evidence.
